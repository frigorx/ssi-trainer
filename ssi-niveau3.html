Aide — SSI Trainer Niveau 3

Principe

Ce simulateur reproduit une baie 19" contenant 5 CMSI interconnectes par bus RS485, chacun gerant 4 zones de detection incendie. Vous devez gerer des crises multi-batiments en temps reel.

Interface

  • LEDs : VEILLE (vert), ALARME (rouge clignotant), DERANGEMENT (jaune), COM (bleu = bus actif)
  • Ecran LCD : affiche l'etat courant de chaque CMSI
  • Points zones : cliquez pour voir le detail — vert = normal, rouge = alarme, jaune = derangement
  • ACQUIT : acquitte les alarmes du module (arrete le clignotement, maintient la signalisation)
  • COMMANDE : ouvre les options de commande (evacuation, rearmement, essai)
  • ISOLER : deconnecte le module du bus RS485

Bus RS485

Les modules communiquent via le bus RS485. Un defaut bus empeche la centralisation. Vous pouvez isoler ou reconnecter individuellement chaque module.

Synoptique

La vue globale en bas affiche l'etat de tous les batiments. Cliquez sur un batiment pour afficher le detail des 4 zones.

Scenarios

Les scenarios sont pilotes par le formateur via le panneau formateur. En mode libre, vous pouvez simuler des evenements manuellement en cliquant sur les zones.

Scoring

Votre score est calcule selon : rapidite d'acquittement, respect des procedures, qualite de la communication inter-batiments.
