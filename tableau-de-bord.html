Suivi par compétences — composante sécurité incendie

Importez les jetons de résultat des élèves pour obtenir la matrice de positionnement par compétence.

🔒 100 % local. Cet outil ne communique avec aucun serveur : les jetons que vous importez restent dans ce navigateur, sur cet ordinateur (stockage local). Aucune donnée d'élève n'est envoyée nulle part. Utilisez « Tout effacer » sur un poste partagé.

📥 Importer les jetons

Sélectionnez (ou glissez ici) les fichiers jeton-ssi_*.json remis par les élèves. L'import est cumulatif ; les doublons sont ignorés.

Cliquez pour choisir ou glissez-déposez les fichiers JSON ici

👥 Liste de classe (optionnel)

Collez une liste — un élève par ligne, Nom ou Nom;Classe — pour faire apparaître aussi les élèves pas encore évalués.
